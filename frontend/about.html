About AutoGrade AI

Empowering educators with AI-assisted grading technology.

Our Mission

AutoGrade AI is an experimental application that uses OCR and AI to grade student exam papers. It extracts and structures answers, evaluates responses, assigns marks and grades, and generates question-level results. Teachers can review and edit results before exporting reports as CSV or PDF. It aims to reduce repetitive grading work, not replace teacher judgment.

How It Works

  1. 1. Upload

    Exam paper, student papers, optional answer key and instructions.

  2. 2. OCR

    Extract printed and supported handwritten content.

  3. 3. Formatting

    Structure questions, subquestions and answers.

  4. 4. Grading

    Evaluate responses using questions, instructions and the key.

  5. 5. Marks & Grades

    Calculate question total marks and grades.

  6. 6. Human Review

    Inspect results, edit marks and export reports.

Guidelines

Clear Question Labels & Marks

Use clear question and subquestion IDs; write marks beside questions where possible.

Objective Questions

Only multiple-choice questions (MCQs) are supported.

Objective Answer Formats

MCQ answers may be handwritten or provided on bubble sheets, if recognizable. Student answer papers must use the same question IDs as the exam paper.

Nested Subjective Questions

Nested subquestions are supported when their hierarchy is clearly labeled.

System Limitations

Optional Questions

Exams requiring students to choose between optional questions are not supported.

Complex Objective Formats

Matching, true/false, and fill-in-the-blanks are outside the current supported scope.

Diagrams and Complex Shapes

Visually complex content in subjective answers may not be interpreted reliably and needs human review.

External API Availability

The system relies on Free Google Gemini API access and LlamaIndex-related services. Usage limits, downtime, or heavy load may cause delays or failures.

AutoGrade AI is an experimental project exploring AI-assisted exam grading. Review the source code to understand its implementation and limitations.
